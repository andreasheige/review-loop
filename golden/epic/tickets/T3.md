# DS-3: Share links

Part of epic `doc-sharing` (see PRD.md).

## Intent

The owner of a document can create a read-only link to it and send it to someone without an
account. Opening the link shows the document without signing in. The owner can revoke the link;
creating a link again after that gives a new one. Creating a link twice without revoking returns
the same link.

## Definition of done

- `PUT /documents/:id/share` (owner only) returns `{ url: "/s/<token>" }`.
- `DELETE /documents/:id/share` (owner only) revokes it; the old URL then returns 404.
- `GET /s/:token` needs no session and returns the document.
- Tokens are unguessable.
- Prisma schema: `Document.shareToken` (unique, nullable).
